Dify / Coze 集成指南

导入 OpenAPI Schema，几分钟搭建一个带支付门槛的 AI 工作流。

第一步：导入 OpenAPI Schema

  1. 在 Dify 中进入 工具 → 自定义工具 → 从 OpenAPI 导入
  2. 粘贴你的 Schema 地址：
    https://你的域名/schema/{GATEWAY_ID}/openapi.json
  3. 导入后出现两个操作节点：proxyRequest 和 pollStatus

第二步：搭建工作流

[开始]
  |
  v
[HTTP 节点: POST /{gatewayId}/{路径}]
  |
  v
[条件判断: 响应状态码 == 402?]
  |
  +-- 是 (需要支付):
  |     | 提取 paymentUrl 和 orderId
  |     | 发送支付链接给用户
  |     | 循环轮询 GET /poll/{orderId}
  |     | 重试请求 + X-Order-Id 头
  |     | 流式输出 AI 回复
  |
  +-- 否: 直接流式输出 AI 回复

第三步：支付流程

  1. 用户收到 X402 支付链接（支付宝）
  2. 用户通过刷脸 / 指纹 / 密码完成支付
  3. 网关收到支付宝异步通知，标记订单为已支付
  4. 工作流轮询检测到状态变更
  5. 流式返回 AI 结果给用户，订单响应完成后即焚

支付后重试

用户支付完成后，使用同一个请求再加一个请求头即可重试：

X-Order-Id: ord_xxxxxxxx

网关验证订单已支付后放行转发到上游 AI，响应结束后立即删除订单。
