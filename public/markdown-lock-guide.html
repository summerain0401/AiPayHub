动态内容锁

保护 .cursorrules、MCP 配置等 Markdown 资产不被白嫖，付费后一次交付、阅后即焚。

工作原理

  1. 创建一个网关，指向上游 Markdown 文件的原始地址
  2. 将代理地址分享给用户，而非原始链接
  3. 未付费用户看到的是支付提示 Markdown
  4. 付费后，完整内容只交付一次
  5. 内容交付后立即从 Redis 中销毁（阅后即焚）

示例：保护 .cursorrules

私有原始地址 
https://raw.githubusercontent.com/user/repo/main/.cursorrules
代理地址（分享给用户） 
https://你的域名/gw_xxx/.cursorrules

用户访问代理地址时看到支付提示。付费后获得完整内容一次，随后订单销毁。

支持的内容类型

  • .cursorrules 文件
  • MCP 服务器配置文件
  • Prompt 模板和技能包
  • 任何 Markdown 或纯文本内容

请求携带 Accept: text/markdown 头时会收到 Markdown 格式的支付提示。
